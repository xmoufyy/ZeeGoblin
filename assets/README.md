# Assets

Branding lives in code (`bot/branding.py`): metallic gold `#D4AF37`, purple `#6A1B9A`,
orange `#FF7A00`, black `#111111`, magenta highlights `#E0119D`, with 👑 crowns throughout.

**`/solpump` artwork:** save the image as `assets/solpump.png` (or `.jpg` / `.webp`, under
8 MB). A 16:9 picture such as 1024×576 looks best. Without it, the card is posted text-only.

Put the bot's avatar and banner here if you want them versioned. Upload them in the Discord
Developer Portal (**your app → Bot → Icon / Banner**); Discord bots can't set rich-presence
images, so the activity line ("Playing Gambling on Solpump") is text only.
